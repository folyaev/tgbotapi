# UT Content Manager

Telegram-бот для сбора медиа из чатов, сохранения файлов на диск и ведения метаданных в SQLite.

## Что делает проект
- Сохраняет медиа из Telegram (фото, видео, документы, анимации, аудио, голосовые и т.д.).
- Формирует карточки контента и позволяет выбрать тему (topic) через inline-кнопки.
- Держит метаданные в `state.sqlite` внутри `BASE_ROOT`.
- Работает с локальным Telegram Bot API (контейнер `tgbotapi`).

## Архитектура (кратко)
- `utmanager/app.py` - точка входа, регистрация хендлеров и команд.
- `utmanager/handlers/media.py` - прием сообщений и загрузка файлов.
- `utmanager/handlers/callbacks/` - обработка inline-кнопок карточек/тем.
- `utmanager/db.py` - схема SQLite и функции доступа к данным.
- `utmanager/topics.py` - синхронизация тем из файловой системы.
- `utmanager/ui.py` - форматирование сообщений и клавиатур.

## Быстрый старт через Docker
1. Создайте `.env` в корне проекта.
2. Запустите:
```bash
docker-compose up -d
docker-compose logs -f utmanager
```
3. Проверьте, что:
- сервис `tgbotapi` поднялся на `:8081`;
- сервис `utmanager` запущен без ошибок в логах.

## Локальный запуск (минимальный)
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m utmanager.app
```

## Основные переменные окружения (`.env`)
- `BOT_TOKEN` - токен бота (обязательно).
- `BASE_API_URL` - URL Bot API, обычно `http://localhost:8081/bot` (или `http://tgbotapi:8081/bot` в Docker-сети).
- `BASE_FILE_URL` - URL для скачивания файлов через локальный Bot API (опционально).
- `BASE_ROOT` - корень хранения файлов и `state.sqlite` (по умолчанию `./downloads`).
- `ALLOWED_CHAT_IDS` - список разрешенных chat id через запятую.
- `OWNER_USER_ID` - id владельца/админа (опционально).
- `TIMEZONE` - часовой пояс, по умолчанию `Europe/Amsterdam`.
- `USE_DATE_BUCKETS` - `0/1`, использовать ли бакеты дат в пути.
- `TGGROUPLINK` - опциональная ссылка на группу.

## Структура хранения файлов
- При `USE_DATE_BUCKETS=1`: `BASE_ROOT/<UTDDMMYY>/<Topic>`
- При `USE_DATE_BUCKETS=0`: `BASE_ROOT/<Topic>`
- Все входящие сначала кладутся в `BASE_ROOT/UNSORTED/<Category>`, затем переносятся в выбранную тему.

## Как работают темы
- Темы подтягиваются из папок в `BASE_ROOT` (или внутри бакета даты).
- В БД темы хранятся отдельно, чтобы карточки/теги не терялись.
- Если папка темы исчезла, тема скрывается из выбора (архивируется), но данные карточек сохраняются.
- Если папка снова появилась, тема автоматически возвращается в список выбора.

## Полезные команды
- Проверка консистентности:
```bash
python -m utmanager.checks
```
- Быстрая sanity-проверка файла:
```bash
python -m py_compile utmanager\handlers\media.py
```

## Эксплуатационные заметки
- Не коммитьте `.env` в репозиторий.
- Регулярно делайте бэкап `BASE_ROOT/state.sqlite`.
- Перед крупными изменениями схемы БД делайте копию `BASE_ROOT`.
- После ручной правки папок тем удобно нажать `Refresh folders` в боте.
